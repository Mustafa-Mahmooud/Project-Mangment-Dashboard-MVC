# Company Management System - ASP.NET MVC

A robust enterprise-grade application built with ASP.NET MVC, implementing modern architectural patterns and secure authentication.

![Project Screenshot](/path/to/screenshot.png) <!-- Add a screenshot if available -->

## 🔥 Features

### Core Functionality
- **Role-based access control** (Admin, Employee, User)
- **Multi-provider authentication** (Email, Google, Facebook)
- **Secure password recovery** (Email + SMS)
- **Employee/Department management** (Full CRUD operations)

### Technical Highlights
- Clean 3-layer architecture
- Repository Pattern + Unit of Work
- AutoMapper for DTO transformations
- Dependency Injection throughout
- EF Core Code-First with migrations
- AJAX-powered real-time search
- Soft delete implementation
- File upload handling

## 🛠 Tech Stack
- **Backend**: ASP.NET MVC, Entity Framework Core
- **Authentication**: ASP.NET Identity
- **Services**: Twilio (SMS), KitMail (Email)
- **Frontend**: Bootstrap, jQuery
- **Tooling**: AutoMapper
